# TallesSound v1

Mobile-first prototype of the TallesSound sample marketplace.

## Intro flow
Open the site -> tap LET'S GO -> intro.mp4 plays with its original audio -> when it ends, the main site appears.

## Main UI
Black / white / red theme, responsive mobile layout, rotating record, categories, sample cards and bottom player.

Upload all files in this folder to a GitHub repository and enable GitHub Pages.
